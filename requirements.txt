# It lives at the top of the repository because that is where a hosted Space
# looks: a Space mounts this one file on its own to install from, with none of
# the repository around it, so a list that points at another file with `-r`
# cannot be followed and the build stops before anything is installed.
#

# alongside this list, and that toolkit needs a newer FastAPI than a single
# pinned version allows — pinning it makes the install fail before anything
# runs. Tested on both ends of the range.
